# 📚 Vimarsh Summer '26 PEP – Solution Bank

Welcome to the official solution repository for the **Vimarsh Summer '26 Programming Excellence Program (PEP)**.

This repository contains reference solutions for:

* 💻 Class problems
* 📝 Homework assignments
* 🎯 Practice questions discussed during the course

## 📂 Repository Structure

Solutions are organized topic-wise. Each folder contains the corresponding problems and their solutions.

## 📌 Before You Look at the Solution

To get the most out of this repository:

1. Attempt the problem on your own.
2. Think of multiple approaches.
3. Only then refer to the solution.
4. Re-implement it without looking.

> **Learning comes from solving, not reading.**
